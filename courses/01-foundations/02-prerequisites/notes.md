## How Does the Web Work?

### Knowledge Check

#### What is a web server?

A computer connected to the internet that stores data and responds to requests.

#### What is a network?

A collection of connected computers.

#### What is the internet?

A large network of connected networks.

#### What is an IP address?

A unique address that identifies a computer connected to a network.

#### What is a router?

A computer that knows how to forward messages between networks.

#### What is an ISP?

A company that manages special routers that are linked together.

#### What are packets and how are they used to transfer data?

Packets are small pieces of data. Larger amounts of data are split into packets and sent individually. When they arrive at their destination, they are reorganised into the correct form.

#### What is a client?

A computer that requests information or services.

#### What is a server?

A computer that stores data and responds to requests.

#### What is a web page?

A single document that can be displayed in a web browser.

#### What is a web browser?

A program that retrieves and displays web pages.

#### What is a search engine?

A web service that helps you find other web pages.

#### What is a DNS request?

A request to convert a domain name into its corresponding IP address.

#### Which browser are you currently using?

Chrome.

#### In your own words, describe the process that takes place when you initiate a search on google.com in terms of what we discussed.

The browser performs a DNS lookup to get the IP address of the corresponding server and sends a request for the data. The request is routed to the correct server, which sends the result back as a series of packets. The browser receives those packets, reorganises them correctly, and displays the result to the user.

## Installations

### Knowledge Check

#### What operating systems does The Odin Project support?

The Odin Project supports macOS and Linux, specifically Ubuntu and official Ubuntu flavors. Windows itself is not supported, but Windows users can use supported Linux environments such as WSL2, a virtual machine, or dual-booting.

#### What browser does The Odin Project support?

The Odin Project supports Google Chrome. Its lessons, screenshots, and developer-tool instructions assume Chrome is being used.

The Odin Project supports Visual Studio Code (VSCode).
