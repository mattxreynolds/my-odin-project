Recipes is the first formal project in The Odin Project Foundations course. The goal is to build a basic multi-page recipe website while applying the HTML concepts covered throughout HTML Foundations.

The project is intended to reinforce document structure, headings and paragraphs, links and relative paths, images, ordered and unordered lists, file organisation, and a meaningful Git commit workflow.

<!--

- Create a main `index.html` page with the standard HTML boilerplate and a heading for the recipe website.
- Create a separate `recipes` directory containing individual HTML pages for recipes.
- Link from the homepage to each recipe page using relative links.
- Provide navigation from each recipe page back to the homepage.
- Include an image of the finished dish on each recipe page.
- Add a description of each recipe using appropriate headings and paragraphs.
- List each recipe's ingredients using an unordered list.
- Present the preparation steps using an ordered list.
- Create three recipe pages following the same overall structure.
- Link all recipe pages from the homepage.
- Make meaningful Git commits throughout development.
