# Complete an Odin course

Read root guidance and repository conventions. Activate only for an explicit course
completion statement, not merely because the last mapped section looks complete.

Compare mapped sections/projects, notes, project READMEs, deployments, Issues, and
current official course requirements where practical. Disclose source uncertainty
and report blockers. Run the read-only audit.

When ready, update root README status and actual completion date. Prepare the
annotated tag exactly as conventions require, but treat tag creation and tag push
as mutations requiring the same exact approval plan as commits and pushes. Keep
README completion and any other concern in appropriately small commits. Stop after
presenting the ordered plan; never infer tag approval.
